Limpeza Automática de Visitantes

Configure a limpeza automática de visitantes. Quando ativado, o sistema irá inativar todos os visitantes ativos às 00:00 e criar tarefas de exclusão para o comunicador processar.

Inativar visitantes ao trocar o dia (00:00)
Zerar estatísticas de ocupação às 00:00
Funcionamento:
  • Às 00:00, todos os visitantes ativos serão inativados
  • Os contadores "Pessoas no Local" e "Visitantes no Local" serão zerados
  • Uma lista de tarefas de exclusão será criada para cada visitante inativado
  • Os logs de acesso serão mantidos
  • O comunicador acessa a lista, deleta os visitantes e resolve as tarefas

Importar Pessoas

Importe pessoas a partir de um arquivo CSV. O formato esperado deve seguir o padrão de exportação.

Selecione o formato do arquivo

📁 Estrutura do Layout 1:

  • Empresas.csv - Lista de empresas
  • Grupos.csv - Lista de grupos
  • Pessoas.csv - Lista de pessoas
  • photos/ - Pasta com fotos (opcional)

📁 Estrutura do Layout 2:

  • groups.csv - Grupos e Empresas (idType: 1=grupo, 2=empresa)
  • peoples.csv - Pessoas e Visitantes (idType: 0=pessoa, 1=visitante)
  • vehicles.csv - Veículos (opcional)
  • photos/ - Fotos no formato: usuario-<id>.jpg

📁 Estrutura do Layout 3 (IDSecure Cloud):

  • Empresas_*.csv - Empresas (delimitador: , ou ;)
  • Grupos_*.csv - Grupos (delimitador: , ou ;)
  • Pessoas_*.csv - Pessoas e Visitantes (delimitador: ;)
  • Veículos_*.csv - Veículos (delimitador: ;)

Importar Fotos do MAMControl (VPS)

Envie o arquivo .db exportado da VPS. O sistema lerá os caminhos de fotos das pessoas, baixará cada imagem diretamente da VPS e atualizará os registros locais automaticamente.

Como exportar o .db: No servidor VPS, copie o arquivo /mamcontrol/backend/databases/tenants/tenant_SEUID.db para sua máquina local.
URL base do servidor MAMControl na VPS (sem barra no final)
Token de autenticação para acessar fotos protegidas na VPS
Banco de dados SQLite exportado da VPS (tenant_SEUID.db)

Processando...

Como Funciona

  1. O sistema abre o arquivo .db enviado
  2. Lê a coluna photo_url da tabela persons
  3. Para cada foto encontrada, faz o download diretamente da VPS
  4. Salva as fotos em uploads/photos/person/
  5. Atualiza o banco local: associa cada pessoa (pelo ID) ao caminho local da foto
Importante: O matching entre VPS e sistema local é feito pelo ID da pessoa. Certifique-se de que o .db é do mesmo tenant que está configurado localmente.
